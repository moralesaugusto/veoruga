## Name
Veoruga

## Summary (≤132 chars)
Snip a region or capture the visible page. Save as PNG or copy to clipboard. No tracking, minimal permissions.

## Description
Veoruga is a fast, no-nonsense screenshot tool that keeps everything on your
device.

• Snip a region — click the icon and drag to select any part of the page.
• Capture visible area — grab the whole viewport in one click.
• Download the shot as a timestamped PNG, or copy it straight to your clipboard.

Privacy first:
• No accounts, no ads, no analytics, no tracking.
• Screenshots never leave your computer — there is no server and no network
  request of any kind.
• Minimal permissions: only "activeTab" (temporary access when you invoke it)
  and "scripting" (to draw the selection overlay). No access to your browsing
  history and no standing access to any website.

Note: browsers do not allow any extension to capture system pages (chrome://…),
the Chrome Web Store, or other extensions' pages.

## Category
Productivity

## Single purpose (for the dashboard)
Capture a screenshot of the current web page — either the visible area or a
user-selected region — and let the user save or copy it.

## Permission justifications
- activeTab: Used only when the user clicks the toolbar icon, to read the
  current tab's pixels so they can be captured. No standing access to any site.
- scripting: Injects the on-page region-selection overlay used for snipping.

## Data usage disclosures
Declare: does NOT collect or use any user data. No data is sold or transferred.
